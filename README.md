# 🧠 Travel Insurance Prediction using Machine Learning

This project aims to predict whether a person is likely to purchase travel insurance based on various features such as age, occupation, income, travel history, and more. It demonstrates the complete machine learning workflow—from data loading to result display—with an interactive user interface.

## 📊 Project Structure

The project follows a modular architecture as outlined in the component and activity diagrams.

### ⚙️ Components
- **User Interface**: Frontend for user inputs and result display.
- **Preprocessing Module**: Handles missing values, feature encoding, and scaling.
- **ML Module**: Trains a machine learning model and makes predictions.
- **Dataset**: Contains training and testing data used for the prediction model.

## 🛠️ Technologies Used
- Python 3.x
- scikit-learn
- pandas
- matplotlib / seaborn (for data visualization)
- UML (Unified Modeling Language) for system design
